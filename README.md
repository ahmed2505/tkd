# TKD_2026: Taekwondo team app

One Node.js app, one MongoDB database:

| URL | Who | What |
|---|---|---|
| `/?c=<code>` | Athletes | Public registration form. Each coach has his own link (the form refuses a missing or wrong code) |
| `/coach` | Coaches + owner | Dashboard. A coach logs in with his own username/password and sees only his athletes. The owner logs in with username `admin` + `ADMIN_KEY` |
| `/admin/export.xlsx` | Coaches + owner | Excel generated live from MongoDB. A coach gets only his athletes; the owner gets everyone (with a coach column) |

## Run locally
1. Copy `.env.example` to `.env` and fill `MONGODB_URI` and `ADMIN_KEY`.
2. `npm install` then `npm start`
3. Open http://localhost:3000 (form) and http://localhost:3000/coach (dashboard).

## Deploy (Render + MongoDB Atlas)
Build command `npm install`, start command `npm start`, env vars `MONGODB_URI` and `ADMIN_KEY`
(optional `SESSION_SECRET`). Send athletes the root link, e.g. `https://your-app.onrender.com/`.
Install the coach dashboard on your phone from `/coach` ("Add to Home Screen").

## Security notes
- Coach login sets a signed HttpOnly, SameSite=Strict cookie (30 days). The key never sits in the URL.
- Athlete data is read-only to the public: the form can only create records; everything else needs the coach cookie.
- Rate limits on the form and on login, a honeypot field, strict input whitelisting, Helmet headers + CSP.
- Evaluation totals are computed on the server; Excel cells are written as plain text (no formula injection).

## v3 additions
- `/athlete`: athlete portal. Each athlete signs in with phone number + personal password and sees only their own evaluations (the coach's private notes are never sent).
- Passwords are generated by the server (8 characters), stored only as scrypt hashes, and shown once: to the athlete after registering, or to the coach (Dashboard: "توليد كلمات السر", per-athlete "كلمة سر"). Resetting logs the athlete out everywhere.
- Coach can edit athletes (weight, belt, ...) and edit evaluations. Notes are optional.
- New criterion "القوة" (power, 0/20). New evaluations are out of 120; older ones stay out of 100.

## v4: multiple coaches
- The owner (`admin` + `ADMIN_KEY`) creates coach accounts in the **المدربون** tab. The coach's password is shown once; each coach also gets a personal registration link.
- A coach sees, edits, evaluates and exports **only** the athletes registered under him (through his link or added by hand). Every API route filters by coach on the server.
- An athlete sees only his own evaluations and the name of his coach.
- Athletes registered before this version have no coach: the owner assigns them (اللاعبون ← تعديل ← المدرب).
- A phone number can belong to one athlete only (it is the athlete login), so it cannot be registered under two coaches.
- Coaches change their own password from **حسابي**. The owner can reset a coach's password, suspend or delete him (delete only when he has no athletes).

## v4.1
